# KLAPS Studio — אתר עריכת וידאו

אתר בעברית (RTL) לסטודיו לעריכת וידאו KLAPS, בקובץ HTML יחיד הכולל CSS ו-JavaScript.
הדומיין המתוכנן: **Klaps.studios**

הקובץ הנוכחי: `klaps-v3.html`

---

## הרצה מהירה

1. פתחו את `klaps-v3.html` בדפדפן. אין צורך בהתקנה או בשרת.
2. להעלאה לאוויר, העלו את הקובץ לכל אחסון סטטי (Netlify, Vercel, GitHub Pages, אחסון רגיל) וחברו את הדומיין.

> הקובץ טוען רק את הפונטים מ-Google Fonts (Rubik, Assistant, IBM Plex Sans Hebrew). אם הם לא נטענים, יש גיבוי לפונטים של המערכת.

## מה יש באתר

**אתר ציבורי**
- Hero, שירותים, התמחות, חבילות, למה Klaps, התוצאות מדברות (עבודות), ביקורות, תהליך עבודה (9 שלבים), מחירון, שאלות נפוצות, צור קשר ו-Footer.
- עמוד מלא לכל חבילה בכתובת `#/p/<מזהה>`, ועמוד 404.
- מצב כהה/בהיר (ברירת מחדל: כהה). הבחירה נשמרת.
- טופס פנייה עם בחירת חבילה, שדה קוד הנחה, אימות שדות והסכמה חובה לתנאי השימוש ולמדיניות הפרטיות.
- טופס השארת ביקורת. הביקורת לא מתפרסמת עד אישור מנהל.

**חבילות, הנחות וקופונים**
- המחיר הנוכחי והמחיר לפני הנחה מוגדרים לכל חבילה. אחוז ההנחה מחושב אוטומטית.
- להנחה אפשר להגדיר תאריך התחלה וסיום. אחרי הסיום מוצג המחיר לפני ההנחה.
- קופונים נבדקים לפי: קיום, פעיל/לא, תאריכים, מספר שימושים מקסימלי וחבילה מתאימה.

**נגישות**
- קישור "דלג לתוכן", ניווט מקלדת, מצבי פוקוס, ARIA ו-HTML סמנטי.
- תפריט נגישות (♿): הגדלה והקטנה של טקסט, ניגודיות גבוהה, הדגשת קישורים ועצירת אנימציות.
- כיבוד `prefers-reduced-motion`.
- הצהרת נגישות.

**משפטי**
- תנאי שימוש, מדיניות פרטיות והצהרת נגישות (נפתחים כחלון מה-Footer ומטופס הצור קשר).
- באנר עוגיות.

## פאנל ניהול

כניסה: `#/admin` (קישור "ניהול האתר" ב-Footer).

- **כניסה ראשונה:** בוחרים סיסמה (10 תווים לפחות). היא נשמרת מוצפנת (PBKDF2-SHA256) ולא מופיעה בקוד.
- **הגנה מניסיונות:** נעילה של דקה אחרי 5 ניסיונות כושלים.
- **מה אפשר לנהל:** חבילות (הוספה, עריכה, מחיקה, שכפול, סידור מחדש, הסתרה), קודי הנחה, ביקורות (אישור/דחייה), עבודות, שירותים, מחירון, שאלות נפוצות, פלטפורמות חברתיות ופניות (כולל סטטוס).
- **הגדרות ותוכן:** כותרות ה-Hero, אימייל, טלפון, מיקום, WhatsApp, שנות ניסיון וצבעי מותג.
- העלאת תמונות: PNG, JPG או WebP עד 400KB.

## חשוב לדעת — מגבלות הגרסה הנוכחית

1. **הנתונים נשמרים בדפדפן בלבד (localStorage).** שינוי שתעשו בפאנל יופיע רק בדפדפן שבו עשיתם אותו, ולא למבקרים אחרים. גם פניות מהטופס נשמרות רק אצל מי ששלח אותן.
2. **אבטחת הפאנל היא בצד הלקוח בלבד.** אפשר לעקוף אותה, ולכן אין להסתמך עליה כהגנה אמיתית. הרשאות, סיסמת מנהל כמשתנה סביבה, CSRF, Rate Limiting ו-Audit Log דורשים שרת.
3. **לא קיימים כרגע:** צ'אט משתמש-מנהל, הרשמה והתחברות למשתמשים, התראות, ספריית מדיה, Audit Log, עריכת הדפים המשפטיים מהפאנל, חיפוש ומועדפים, Sitemap/robots ו-Structured Data.
4. **החבילות, העבודות והמחירון הם נתוני דוגמה.** יש להחליף אותם דרך הפאנל. אין באתר תמונות עבודה אמיתיות, והוויזואלים הם מעברי גוון ומסגרות.
5. **המסמכים המשפטיים הם נוסח בסיס ואינם ייעוץ משפטי.** יש להשלים את השדות שבסוגריים מרובעים (פרטי העסק, עיר שיפוט, מע"מ, רכז נגישות) ולאשר אותם מול עורך דין.
6. הקוד עבר בדיקת תחביר בלבד. לפני עלייה לאוויר יש לבדוק ידנית ב-Chrome, Safari ו-Firefox, במובייל ובדסקטופ.

## מבנה הקוד

הכל בקובץ אחד, בסדר הבא:

| חלק | תיאור |
|---|---|
| `<style>` | משתני CSS (צבעים, פונטים), עיצוב רספונסיבי, אנימציות, מצב בהיר/כהה |
| `SEED` | נתוני ברירת המחדל (חבילות, שירותים, עבודות, מחירון, FAQ, הגדרות) |
| `S` / `save()` | "מסד הנתונים" ב-localStorage (מפתח: `klaps_v2`) |
| `cur` / `dOn` / `coupon` | לוגיקת מחירים, הנחות וקופונים |
| `home` / `pkgPage` | רינדור האתר ועמוד חבילה |
| `route` | ניתוב לפי ה-hash: `#/`, `#/p/<id>`, `#/admin` |
| `DOCS` | נוסח תנאי השימוש, הפרטיות והנגישות |
| `SC` + `admin` / `form` | פאנל הניהול (טפסים נוצרים מסכמה אחת) |

מפתחות localStorage נוספים: `klaps_admin` (סיסמה מוצפנת), `th` (ערכת נושא), `ck` (עוגיות), `fs` ו-`a1` (נגישות).

## איך לעבור לגרסת פרודקשן

הצעד הבא הוא להחליף את ה-localStorage ב-API ומסד נתונים:

1. **Backend:** למשל Next.js עם PostgreSQL (או Node/Express). טבלאות מוצעות: Users, Packages, Coupons, Portfolio, Reviews, Requests, Conversations, Messages, Pricing, SiteSettings, SocialPlatforms, Media, FAQ, LegalPages, AuditLogs.
2. **אימות:** סיסמת מנהל כ-Environment Variable, Hashing בשרת (bcrypt/argon2), Sessions ב-Cookie עם HttpOnly, Secure ו-SameSite.
3. **אכיפה בשרת:** אימות הנחות וקופונים, בדיקת הרשאות בכל פעולת Admin, Rate Limiting והגנת CSRF.
4. **קבצים:** העלאה לשרת או לאחסון ענן עם בדיקת MIME וגודל ושינוי שם הקובץ.
5. **צ'אט והתראות:** WebSocket או Polling, כשכל משתמש רואה רק את השיחות שלו.
6. **SEO ותשתית:** Sitemap, robots.txt, Open Graph, HTTPS ו-Caching.
